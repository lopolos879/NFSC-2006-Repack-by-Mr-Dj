INSTALLATION INSTRUCTIONS:

1. Go to the link below:
"[https://drive.google.com/drive/folders/1cVCv6QrHvKLwugmDhNDFOvsA1--vC5sm](https://drive.google.com/drive/folders/1cVCv6QrHvKLwugmDhNDFOvsA1--vC5sm)".

2. Download the file "*Need for Speed - Carbon.zip*".

3. Extract the contents to a folder of your choice.

4. Locate and run the "*Setup.exe*" file inside the "*Need for Speed - Carbon*" folder.

5. In the installer window that appears, click the "*Install*" button and wait for the installation to complete.

6. Done—the game is installed and ready to launch.

P.S.:
The game files can be found in the "*Mr Dj*" folder within "*Program Files (x86)*", while save files are located in the "*Documents*" folder.

Also:

DO NOT CHANGE THE GRAPHICS SETTINGS; otherwise, the game will freeze, and restarting your device will be the only solution.
